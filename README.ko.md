> **이 포크에 대해.** [yethihahtwe/token-tv](https://github.com/yethihahtwe/token-tv)는
> [click6067-ship-it/token-tv](https://github.com/click6067-ship-it/token-tv)의 포크입니다. 달라진 점:
> - **GeekMagic SmallTV-Ultra 지원** (펌웨어 Ultra-V9), 자동 감지. 기존 SD_PRO 시계는 그대로 동작합니다.
> - **모든 화면에 두 사용 한도 표시.** 카드마다 더 많이 쓴 한도 아래에 다른 한도(예: 주간 아래 5시간)의
>   막대와 리셋 시간을 추가합니다. 서비스가 세 개면 공간이 없어 막대 하나만 보입니다(Retro는 오른쪽 상자에 표시).
>
> 라이브 데모와 화면 갤러리는 원본 프로젝트의 것이라 원본 화면을 보여 줍니다.

약 5달러 Wi-Fi 책상 시계에 Claude·Codex 사용 한도를 띄웁니다. 펌웨어는 그대로예요.  
**구경하기:** [라이브 데모](https://token-tv.vercel.app) 또는 `npx github:yethihahtwe/token-tv demo`, 시계·로그인 없이 바로.  
**설치하기:** 이 저장소를 AI에게 주고 *"TokenTV 설정해줘"* 라고 하세요. AI는 [AGENTS.md](AGENTS.md)를 따릅니다.  
**내 화면 만들기:** 시계 없이 [Game Boy 예제](examples/gameboy)에서 시작해 AI에게 바꿔 달라고 하세요. [가이드](docs/clock-faces.md) · [공유하기](https://github.com/click6067-ship-it/token-tv/issues/new?template=share_a_face.md)
